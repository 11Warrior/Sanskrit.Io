# Sanskrit.Io

A web application focused on providing resources and tools for learning and engaging with Sanskrit.

## Key Features & Benefits

*   **Interactive Learning Resources:** Provides access to various Sanskrit learning materials.
*   **Modern Frontend:** Built with Svelte and Vite for a fast and responsive user experience.
*   **Custom Fonts:** Utilizes custom fonts (Edensor, Lato) for a unique and engaging visual presentation.

## Prerequisites & Dependencies

Before you begin, ensure you have the following installed:

*   **Node.js:** (Version >= 16) - JavaScript runtime environment.
*   **npm:** (Node Package Manager) - Package manager (usually comes with Node.js).
*   **VS Code** (Recommended): Code editor with Svelte extension for optimal development.

## Installation & Setup Instructions

1.  **Clone the repository:**

    ```bash
    git clone https://github.com/11Warrior/Sanskrit.Io.git
    cd Sanskrit.Io
    ```

2.  **Install dependencies:**

    ```bash
    npm install
    ```

3.  **Start the development server:**

    ```bash
    npm run dev
    ```

    This will start the application in development mode.  You can usually access it at `http://localhost:5173/` (or similar, depending on your Vite configuration).

## Usage Examples & API Documentation

Currently, there is no API documentation available as the project is focused on frontend presentation. Example usage involves navigating through the learning resources provided on the website.

## Configuration Options

The `vite.config.js` file (which is not included, but typically exists in Svelte/Vite projects) allows configuration of the Vite build process. You can configure:

*   **Server settings:**  Port, hostname, proxy.
*   **Build settings:**  Output directory, bundling options.
*   **Plugin configuration:**  Settings for Svelte and other Vite plugins.

Environment variables are not extensively used but can be added and accessed within the Svelte components using standard JavaScript methods.
